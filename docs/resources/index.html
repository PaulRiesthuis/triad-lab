Interactive Tools & R Packages

Free, open-source web applications and computational packages to support researchers with power analyses, effect size justifications, ROC curve modeling, and interval-based hypothesis testing.

Interactive Shiny Apps & Web Applications

SESOI Decisions

Web Application • Interval Hypothesis Testing

An interactive decision-support application for evaluating practical and theoretical relevance under statistical uncertainty. Provides automated guidance and power assessments for minimum-effect and equivalence testing against non-zero nulls.

Associated Publication: Decisions under uncertainty: A Statistical framework for evaluating practical relevance in interval-based hypothesis testing (Behavior Research Methods, 2026).

Launch SESOI Decisions App BRM Paper & Materials GitHub Source

SESOI Generator

Web Application • Effect Size Justification

A specialized tool to help researchers formulate, justify, and contextualize the Smallest Effect Size of Interest (SESOI) for their experimental paradigm using expert consensus rules and LLM-assisted justifications.

Associated Publication: From expert consensus to large language models: What information is needed to determine and justify a contextualized smallest effect size of interest? (Psychological Methods, 2026).

Launch SESOI Generator App Preprint & Materials GitHub Code

ROC Power Shiny App

Shiny App • Eyewitness & ROC Modeling

Perform simulation-based power calculations for Receiver Operating Characteristic (ROC) curve analysis. Allows researchers to calculate required sample sizes for null hypothesis, minimum-effect, and equivalence testing of Empirical Area Under the Curve (\(AUC\)) differences.

Associated Publication: Ready to ROC? Power Analyses for ROC Curves (Behavior Research Methods, 2025).

Launch Shiny App R Package Repo Tutorial

Interpret Effect Sizes App

Shiny App • Effect Size Interpretation

An interactive application for exploring, visualizing, and translating various effect size metrics (Cohen’s \(d\), Hedge’s \(g\), \(\eta^2\), Odds Ratios) into overlap percentages, probability of superiority, and practical benchmarks.

Associated Publication: Meaningful approaches to assessing the size of effects in memory research (Memory, 2025).

Launch Shiny App GitHub Repo App Overview

Memory Simulation Power App

Shiny App • Memory Experiment Design

Tailored power calculation tool for cognitive memory experiments (Old/New recognition, 2AFC, DRM paradigms) using Monte Carlo simulation methods to account for trial-level noise and participant variability.

R Packages & Computational Software

ROCpower

R Package • GitHub

An R package for simulation-based power analyses of Receiver Operating Characteristic (ROC) curve experiments. Supports parametric and non-parametric Area Under the Curve (\(AUC\)) estimation, equivalence testing bounds, and minimum-effect hypotheses. 

# Install from GitHub
devtools::install_github("PaulRiesthuis/ROCpower")

GitHub Repository BRM Paper

interpreteffect

R Package • GitHub

An R library designed to convert, visualize, and benchmark empirical effect sizes across psychological and medical research designs, with built-in plotting functions for equivalence intervals and confidence bounds. 

# Install from GitHub
devtools::install_github("PaulRiesthuis/interpreteffect")
